# Security reporting

Report suspected vulnerabilities privately to [contact@saboreq.xyz](mailto:contact@saboreq.xyz), with the subject “RenderHalo security report”.

Include the affected page or feature, impact, and minimal reproduction steps using accounts and content you own. Do not include credentials or other users' data. Avoid testing that spends sponsored credits, disrupts service, or accesses someone else's content.

Please do not publish exploit details in public issues before the report has been assessed. No response-time or bounty commitment is made by this document.
